    Install

    npm install alawonn-font

    Use it

    Import the package once, in your app's entry file or root layout:

    import "alawonn-font";

    Then set the family:

    font-family: "Alawonn", cursive;

    This works with React, Vue, Svelte, Astro and Next.js. In Nuxt, add "alawonn-font" to css in nuxt.config.ts. In React Native, load alawonn-font/dist/Alawonn-Regular.ttf with expo-font.

    Desktop apps

    Download the TTF and install it. On Windows, right-click and choose Install. On a Mac, open it and choose Install in Font Book. It appears as Alawonn in your font menu.
