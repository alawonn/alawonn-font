# Security

Alawonn ships font files and a stylesheet. It has no runtime code, but a malformed font file can still crash or confuse a font renderer.

If you find a font file in this project that crashes an app, a browser or a font tool, or anything else you think is a security problem, report it privately through [GitHub's private vulnerability reporting](https://github.com/alawonn/alawonn-font/security/advisories/new). Please don't open a public issue for it.

Include the file and version, the app or tool and its version, the operating system, and the steps that trigger the problem. You'll get a reply within a week.

Only the latest release gets fixes.
